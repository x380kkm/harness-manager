# 组件与 Skill 管理

安装, 配置或更新开发辅助组件时应用本节.

- CodeGraph, Archify, clean-tools, Skills, 适配器和宿主配置各自保有声明接口与来源.
- 通过 Harness Manager 查询已登记组件和安装选择, 使用组件声明的安装及更新入口.
- 项目定制保存在项目配置或独立 Skill 中, 上游工具按照其发布方式更新.
- 调用 Skill 前完整读取所选说明和该任务必需的资源, 按其适用范围使用.
- Hooks 承担确定性的生命周期操作, 模型审查和探索作为显式任务执行.
- 新增组件, 启用 Hooks 或改变现有用户选择时确认授权范围, 输出实际生效结果和需要用户处理的差异.
