# 命令与 PowerShell

执行命令时应用本节, Shell 和工具链以项目要求及当前环境为准.

- 使用当前 Shell 的变量, 引号和路径语法, 将参数边界传到实际执行的程序.
- 使用项目提供的构建和检查入口, 保留锁文件及项目声明的运行时和依赖版本.
- 检查命令退出状态再执行依赖该结果的操作. 将工具约定的无匹配与运行错误分开处理.
- Windows 项目采用 PowerShell 时使用可用的 PowerShell 7, 脚本开头设置 `$ErrorActionPreference = 'Stop'`. 原生命令另行检查 `$LASTEXITCODE`, `rg` 的 1 表示无匹配, 2 表示错误.
- PowerShell 文本读写明确使用 UTF-8 编码, 参数取决于实际命令支持的接口. 复杂引号组合拆成独立调用.
- 执行删除, 覆盖或移动前核对实际目标, 按授权范围操作并保留需要恢复的用户内容.
