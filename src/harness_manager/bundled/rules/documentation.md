# 文档维护

创建或维护项目文档时应用本节, 内容规模依据读者和项目用途决定.

- README 说明项目用途和实际运行入口, 项目指令说明协作者需要遵守的约定.
- 教程, API 文档, 架构说明和贡献指南按实际阅读需求组织, 保持每项事实有明确的维护来源.
- 生成文档通过对应的来源和生成入口更新, 手写文档与相关实现一起维护.
- 说明必要的运行条件, 外部契约, 兼容性限制和设计取舍, 使用可核对的事实.
- 文档语言沿用项目约定, 使用半角 ASCII 标点, 中文与 Latin 字母或数字之间保留一个空格.
- 项目文档保留持久信息, 会话进度和一次性分析存放于项目约定的私人工作位置.
- 文字审查聚焦变更中的准确性, 清晰度和来源一致性. 删除既有文档依据用户授权和项目维护约定执行.
