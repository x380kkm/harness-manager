# 跨代理交接

通过 Git 状态, 项目交接文件和必要的会话记录衔接工作. 项目约定保存在项目指令中, 当前进度保存在私人交接文件中.

## 解析路径

从用户明确指定的项目或当前执行目录确定目标. 从本 Skill 的实际安装位置运行 [路径解析脚本](scripts/resolve_paths.js):

```text
node <Skill 目录>/scripts/resolve_paths.js --project <项目目录>
```

脚本只读解析路径, 输出 JSON:

- `projectRoot`: Git 工作树根目录; 普通目录使用指定项目目录.
- `sharedRoot`: Git 登记且可确认的主工作树. bare 仓库, 分离的 Git 元数据等情况可能无法反查主工作树, 此时保留当前工作树并返回 `warnings`; 跨工作树共享位置由项目明确指定.
- `handoffDir`: 默认是 `sharedRoot/archive`. 已有约定通过 `--handoff-dir` 传入; 相对位置基于 `sharedRoot`.
- `gitExcludeFile`: Git 实际使用的本机忽略文件, 同时适用于 `.git` 是文件的关联工作树.
- `codexSessions`: `CODEX_HOME/sessions`, 未设置时使用当前用户主目录下的 `.codex/sessions`.
- `claudeProjects`: `CLAUDE_CONFIG_DIR/projects`, 未设置时使用当前用户主目录下的 `.claude/projects`.

`--codex-home` 和 `--claude-home` 可指定明确的宿主配置目录, 优先于环境变量. 路径由当前操作系统解析, 支持空格和中文. 输出同时标明会话目录是否存在; 缺失目录表示当前机器没有该位置的日志.

宿主运行在其他机器或容器时, 在对应环境解析路径. 其他 Agent 使用其提供的会话查询入口或明确的日志位置. 日志不可用时, 依据工作树和交接记录继续可确认的工作.

## 交接文件

优先沿用项目已有的私人交接位置. 没有约定时使用 `handoffDir/YYYY-MM-DD-handoff.md`, 按当前环境的本地日期命名. 日期最新的一份记录当前状态, 新文件承接上一份的现状和待办.

交接记录只在本机保存. 位于仓库内时, 先检查实际文件是否被 Git 忽略; 需要增加本机忽略项时写入 `gitExcludeFile`, 保留原有内容. 位于仓库外时沿用该位置的私有存储约定. 多工作树共用交接记录时写明每项工作的实际路径和分支.

```markdown
# <项目> 交接

执行者: <Agent 标识或空闲>, <开始时间和时区>

## 现状
目标, 仓库与分支, 最近验证的提交, 未提交内容及其来源.

## 待办
剩余工作及验收方式.

## 记录
### <时间和时区> <Agent 标识>
- 改动: 文件或模块, 以及原因.
- 验证: 检查及结果.
- 提交: 提交标识, 或未提交的原因.
- 下一步: 接手者首先需要确认的事.
```

## 开始与结束

1. 读取交接记录. Git 项目用 `git status` 和 `git log` 核对工作树, 普通目录依据当前文件和已有记录核对. 首次交接依据项目 README, 实际状态和必要的会话记录建立文件.
2. 另一执行者仍登记为活动时, 通过宿主当前状态或用户确认其已停止. 历史日志和执行者字段是协作记录, 不能单独证明当前是否仍在运行. 无法确认时先询问用户.
3. 查明记录之外的改动来源, 再登记当前执行者和开始时间. 保留其他执行者的修改.
4. 按项目约定提交可验证的工作单元并记录. 结束时更新现状和待办, 对未提交内容逐项说明来源及用途, 将执行者设为空闲.

破坏性 Git 操作需要明确授权和覆盖实际受影响内容的备份. 备份分支只保存提交, 未提交及未跟踪文件需要另行保全. 推送, MR 和发布按用户授权执行.

## 查看会话记录

先用宿主提供的会话查询能力定位目标. 需要读取本地 JSONL 时, 从解析结果中的目录筛选对应会话, 核对记录的项目路径, 时间和会话 ID. Claude 的项目目录名由宿主生成, 通过现存目录及会话元数据定位, 不自行推算编码. 线程创建目录可能与后来命令的工作目录不同, 判断改动归属时核对实际命令的工作目录.

只读取本任务相关的时间范围. [会话摘取脚本](scripts/session_extract.js) 支持 Codex 和 Claude 的 JSONL 记录:

```text
node <Skill 目录>/scripts/session_extract.js <会话文件> <起始 UTC> <结束 UTC> [每类保留条数]
```

时间范围为 UTC ISO 前缀, 下界包含, 上界不包含. 输出时间统一为 UTC, 本地时间转换使用当前环境时区. 默认每类保留 60 条, 消息最多显示 900 字符. 文件和命令来自日志中的工具请求, 实际成功与否仍需结合工具回执和 Git 状态判断. 私人会话原文保留在本机.
